UX challenge

Merchants want loyalty live fast — without a maze of rules and settings. The challenge: a short path from Shopify install to a live dashboard, then creating the first program with AI instead of filling empty forms alone.

One source

Primitives and semantic tokens live in one place — no one-off values on individual screens.

Named by role

Tokens describe purpose — primary text, focus, error — so Loom UI stays coherent when themes or states change.

Built for reuse

Buttons, fields, cards, and chat patterns pull from the same set across install, studio, and dashboard.

Ready to hand off

Short specs beside controls support design review, development, and AI-assisted screen assembly.
